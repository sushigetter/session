SESSION — static PWA
Upload index.html, manifest.json, sw.js and icon.png to the root of an HTTPS static website (for example GitHub Pages). Open the resulting URL in Safari on iPhone, Share > Add to Home Screen, then launch while online once to cache the app. Test airplane mode. No account or server-side database is used by the app. Data is stored in localStorage for the installed app's origin, not automatically in Files. Export JSON backups regularly; changing the URL, deleting the app or clearing website data can lose access to records. Restore replaces existing records after confirmation. Do not change the hosting URL after installation without exporting first.
